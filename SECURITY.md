# Security

The skill runs on your machine inside Claude Code. Its scripts read local files and open local HTML pages in a headless browser; they send nothing anywhere except the Google Fonts request a page makes.

If you find a way for a page, a prompt or a script in this repository to run code you did not expect, read files it should not, or send data out, please report it privately from the **Security** tab of this repository (**Report a vulnerability**). Do not open a public issue for it.

Expect a first reply within a few days. Fixes go into `main` with a new plugin version number, so updating the plugin picks them up.
