# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good intent, critique the work and never the person, and make it easy for newcomers to take part.

## Reporting

If someone in this project's issues, pull requests or discussions behaves in a way that breaks the code, report it to the maintainers privately:

- open a private report from the repository's **Security** tab (**Report a vulnerability**) and start the title with "Conduct", or
- use GitHub's **Report content** option on the comment or post.

Maintainers will keep the report confidential, reply within a few days, and act in line with the enforcement guidelines of the Contributor Covenant.
